# notes/ -- your brain, the AI's inbox

| Folder | What goes in |
|---|---|
| `daily/` | one note per day (Obsidian's Daily note button): what you decided, what's next, loose ideas -- 3-5 lines |
| `ideas/` | one note per idea (units, bosses, maps, UI, events...) -- template: `templates/idea.md` |
| `moc/` | maps of content -- one summary note per topic once it gets messy |
| `templates/` | the daily / idea templates and the consolidate prompt |
| `attachments/` | screenshots and images you paste |

The AI does not read notes/ on its own (that would cost usage every session). Point at a note when it matters
("read notes/ideas/boss-rush.md and write a proposal"), or run the consolidate prompt in a fresh chat.
